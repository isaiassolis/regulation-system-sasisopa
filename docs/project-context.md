# Regulation System SASISOPA — Contexto del proyecto

## Descripción

Regulation System SASISOPA se presentó comercialmente como una plataforma para ayudar a **conformar, implementar y dar seguimiento al SASISOPA** en estaciones de servicio. Su folleto describe gestión de entregables, configuración de actividades, monitoreo de avances y gestión geográfica de estaciones.

## Mi participación

Durante mi etapa como **Gerente Técnico de Plenumsoft Energy & Sustainability**, fui **líder del proyecto y del desarrollo tecnológico de Regulation System SASISOPA**.

## Relación con HENDU

- **HENDU**: producto de administración de información técnica y conocimiento para Oil & Gas.
- **Regulation System SASISOPA**: producto **independiente**, orientado a la gestión y seguimiento del SASISOPA.
- **Interoperabilidad**: ambos productos **podían compartir datos**.

Esta relación no implica que hubiera un único código base, base de datos compartida o protocolo de integración específico. El mecanismo aún no se ha documentado públicamente.

## Funciones descritas en el folleto

En la **primera página** se destacan cuatro capacidades: administrar entregables, configurar actividades, monitorear avances e implementar SASISOPA.

En la **segunda página** se presentan: administración geográfica de estaciones de servicio, seguimiento a bitácoras e información requerida, acceso organizado a entregables, planificación de actividades y requerimientos operativos. También figuran monitoreo de KPI y un ciclo de identificar, planear, monitorear y mejorar, con líneas temáticas de riesgos, prevención, emergencias y mejora continua.

El folleto incluye imágenes comerciales de la interfaz, pero no permite auditar las funcionalidades ni comprobar el estado de despliegue de cada una.

## Tecnología e infraestructura

**Pendiente de confirmar.** No se atribuye a Regulation System SASISOPA el stack conocido de HENDU sin evidencia adicional. Asimismo, un logotipo de proveedor de nube dentro del folleto no basta para determinar el entorno técnico real.
